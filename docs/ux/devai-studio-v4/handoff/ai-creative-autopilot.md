# AI creative autopilot — authoritative product requirement

User instruction supersedes earlier manual visual-direction fields. The user chooses a researched/custom topic and Carousel, Reel or Both. AI creates the content outline, copy, backgrounds, composition, typography, visual assets, Reel script/scenes/audio/subtitles and the final video. Users do not supply a layout, background idea, scene prompt, font system or art direction. The app must not assemble carousel artwork from fixed layouts or text overlays. Each slide is an entire AI-generated1080×1350composition. Reel requires a decoded and validated1080×1920MP4,30–40seconds; script/storyboard/collage alone never counts as video.

The application UI tokens are not a fixed Instagram artwork palette. Forest/cream/peach belongs to the app shell. Generated content may use diverse colors, dark/light treatments, photographic/illustrative/abstract scenes, textures, spatial compositions and backgrounds as appropriate to the subject. Brand identity is a small optional studio signature and factual/editorial consistency, not the same background ten days in a row. No mandatory layout library, theme selector or visual brief appears in generation configuration. AI creative plan is inspectable read-only for transparency, never required input.

## Generation flow

1. Topic and evidence gate: determine supported facts, excluded/unsupported claims and editorial angle automatically; user may correct factual copy. No visual task assigned to user.
2. Read recent visual history for this workspace/account: last30published posts, all next14daysscheduled/approved outputs and last10generated concepts. New workspace uses empty history, not sample similarity claims.
3. AI proposes3creative concepts from topic semantics. Each includes background description, material/texture, dominant colors, composition family, art medium, typography intent, scene motifs and expected carousel/Reel continuity. These metadata describe an AI plan, not a rigid rendering template. No user choice required.
4. Rank against history; choose a subject-relevant concept with lowest resemblance within acceptable readability/brand constraints. Reserve its visual fingerprint under generation intent key so concurrent Both or two devices cannot independently repeat the same recently planned concept.
5. AI generates full slides or scene visuals/video from chosen concept, preserving source attribution and exact factual text checks. A carousel has coherent identity across its slides with meaningful changes in imagery/background/scale; a Reel has coherent narrative with scene variation. Both may share the narrative concept but each output is independently generated, reviewed and published.
6. Validate factual transcript, dimensions, legibility, assets and diversity. Similarity failure triggers an automatic new concept/background and scoped regeneration, preserving successful valid assets where coherent.
7. Present generated output, not an empty design canvas demanding layout work. User actions: Edit factual copy, Regenerate slide/scene, Make this post look different, Regenerate format, Preview, Review. Optional editing of copy/audio/timing remains available; no manual visual direction required.

## Diversity policy and limits

Store creativeConceptId and per-asset fingerprints: mediaSHA256,perceptualHash,normalized image embedding,estimated dominant palette,background descriptor,composition/medium labels. Compare on full output previews and representative keyframes; Reel also compares scene imagery and shot sequence. Text semantic overlap alone must not classify a fresh visual as duplicate. Never persist face identity embeddings; only whole-image creative similarity.

Hard gates: exact duplicate imageSHA256or videoSHA256cannot become a new current post; reused source media must be explicitly detected and disclosed (licensed reference assets are not treated as generated fresh output). PerceptualHash Hamming<=6of64or cosine similarity>=0.92with recent representative art flags near duplicate. Repeated background+composition+medium combination within last10posts flags review even if topic/copy differs. Palette alone never blocks, and isolated slide continuity within the same carousel is expected. Thresholds are initial product defaults requiring dataset calibration; until calibration is verified, label checks 'Similarity checks passed', not 'Guaranteed unique'.

Automatic retry budget: at most2alternate concepts beyond the initial concept; unit generation retry follows job cap3attempts, with total authorized generation budget persisted and visible. Exceeding the budget stops and preserves valid output with 'This draft still looks similar to recent content'. Review is blocked for exact/near duplicate; user may choose 'Try a different look' with explicit additional generation authorization or keep as draft/export. Repeated style-combination warning (not near duplicate) allows reviewer acknowledgment explaining intentional series continuity; no invisible bypass. No infinite retries or hidden cost. Estimate shows number of outputs/units and included attempts; monetary amount only when provider pricing verified.

Comparisons inspect last10published posts even if older than30days; maximum history50outputs for efficient validation. Scheduled/approved reservations included to avoid ten concurrently scheduled posts sharing the same concept. If fewer than10posts, use all available and display comparison count. Diversity history is server-side and visible on both devices; deleting a draft removes its reservation unless already published, while published metadata remains for creative history without retaining deleted private payload. Account switching reruns relevant account history check before approval; no account context available uses workspace history. AI research does not invent recent post performance or visual analysis results.

## Controls and states

CREATE-02 shows 'AI handles the visual design' and read-only 'Compared with your recent posts' context. No background/layout/creative-brief input. GEN-01/GEN-02 add stages 'Planning a fresh concept' and 'Checking similarity'. Progress reports actual concept/unit attempts; no fake percentage. CAR-01 and REEL-01 expose 'Make this post look different' in More and 'Regenerate' on selected unit; both choose fresh AI direction automatically. Confirmation explains preserved assets, approval invalidation, budget and target scope. No prompt text area.

'Inspect creative plan' opens read-only drawer/sheet showing AI rationale and compared history count; unavailable history says 'No recent posts to compare'. 'View comparison' opens current draft and closest recent/scheduled output with dates and similarity reason. This is an explanation, not a claim of copyright uniqueness. 'Try a different look' creates new concept version, invalidates relevant output approval and media currentness; already authorized scheduled snapshots remain frozen until explicit reapproval/update. Factual evidence changes still block dependent reservations. Cancelling a job preserves old images/render and unfinished new concept state.

Diversity result states: checking; passed; repeated-style warning; near-duplicate blocked; exact-duplicate blocked; comparison unavailable; retrying alternate concept; budget exhausted. Comparison unavailable permits a draft but blocks automatic 'freshness passed'; reviewer may consciously acknowledge unavailable check for first-party publication, with warning retained. Exact/near-duplicate must be resolved before approval. Source/caption validation is independent of visual freshness. Auto draft schedule may generate varied content; it never approves or publishes without explicit user authorization.

## Backend additions (all proposed)

POST /v1/setups/{id}/generate `{expectedRevision,formats,creativeMode:'ai_autonomous',diversityPolicyRevision,confirmedBudget}`; never accepts requiredlayout/template/backgroundprompt. GET /v1/creative-history?accountId=&limit=50 returns permitted thumbnails,concept metadata,similarity vectors server-side (raw vectors not sent to client). GET /v1/outputs/{id}/creative-plan returns current concept,read-only rationale,comparisonCount,diversityState,nearestOutputSummaries,budgetRemaining. POST /v1/outputs/{id}/different-look `{expectedRevision,scope:'output'|'slide'|'scene',unitId?,excludeConceptIds,confirmedBudget}` →202job,newConceptId; same key returns same job. POST /v1/outputs/{id}/diversity/check `{expectedRevision,accountId?}` →202validationjob. POST /v1/outputs/{id}/diversity/acknowledge `{expectedRevision,reason,warningId}` only repeated-style or unavailable-check warning; exact/near-duplicate acknowledgment rejected. Approval snapshot binds diversityPolicyRevision/result and reviewed media hashes.

No such history,planner,embedding checks or Reel pipeline exists in the audited application. Engineering implements these before enabling 'AI fresh concepts' claims. Current carousel artwork generation already provides full compositions; preserve that capability instead of adding fixed app-rendered templates.
