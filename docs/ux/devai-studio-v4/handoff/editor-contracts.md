# Editor implementation contract

## Carousel

Artwork is a complete generated raster composition, including typography. The canvas cannot pretend to provide movable text layers, font-size handles or template changes. AI chooses composition/background from visual history, without required user direction. Copy fields edit the factual generation input; saved copy marks its image stale. Regeneration submits saved copy/evidence/AI-concept input hashes and retains every old asset. No user layout direction is required. AI selects varied concepts and generates the full composition. Currentness requires generationInputHash == current slideInputHash and successful dimensions/transcript validation. Slide selection uses stable ID and preserves per-slide buffer. Filmstrip thumbnail72×90desktop,56×70iOS; desktop inspector320px,canvas fits4:5with maximum560pxwide; full image export1080×1350.

Reorder via drag or Move before/after presents target stable ID. Begin drag does not write; drop submits complete order under CAS. ESC cancels without mutation. Keyboard Alt+Up/Down moves one position; announce 'Slide2moved to5of8'. Every affected ordinal baked into composition becomes stale. Add allows1–8draft slides; review/generation output gate6–8. Delete selected requires confirmation and chooses next surviving slide; Undo restores as new revision. Per-slide generation disables its own Regenerate, not unrelated copy. Submit disabled while any referenced image stale, missing, generating, unsupported evidence or invalid dimensions. Downloading old assets labels retained version, not current export.

## Reel desktop

Player uses retained validated rendition with explicit revision, or storyboard still mode clearly labeled. Playhead is preview-only and updates at display cadence while announcement happens only on deliberate seek. Time ruler units seconds,100mscueprecision; timeline zoom40–120px/sec default60; horizontal scroll stays inside timeline; tracks Scenes/Voice/Music/Subtitles. Frame stepping ±1/30sec via comma/period in focused player only. Space toggles playback except in input; arrows seek1sec; Shift arrows5sec. Selection enters inspector, not script mutation. Scene trim handles44pxtarget with numeric equivalent; trim modifies sourceIn/sourceOut within decoded source range; playback speed fixed1×initial release. Duration change and scene reorder update subsequent start times deterministically; subtitle cues anchored to sceneID+localOffset and rebase on reorder; manual overlapping cues require resolution. Total target30–40sec may be violated in draft but blocks render/review.

Voice selection is not audio synthesis. 'Generate voiceover' explicitly POSTs /v1/outputs/{id}/voiceover with saved scriptHash/voiceID/confirmed flag. Audio phases distinguish not selected, selected, generating, ready, failed and stale. Existing audio retained while generation pending. Music licensed uploads decoded before use; mix gain -60..6dB, ducking -12dB during voice with100msattack/300msrelease. Normalize final mix -16LUFS integrated target, true peak<=-1dBTP; actual metrics persisted; unsuitable clipping is validation error. None is explicit intentional silence, never silent fallback after failure.

Subtitle initial cues generated from narration alignment; 'Generate subtitles' POST /v1/outputs/{id}/subtitles with audioHash/language. Editable text/start/end and style; cues0.1secresolution, start<end,<=renditionduration, no overlap. Burned subtitle rendering is validated for safe area/readability. Changes mark rendition stale. Caption (Instagram post text) is separate from subtitles (on-video text); never share fields.

Render captures immutable timelineRevision, all source media/audio/cue hashes. Render stage states rendering→rendered→validating→validated; failed render preserves existing validated MP4. Validate decode, video1080×1920, H.26430fps, duration30–40seconds, AACwhen audio, matching input hashes, no missing source frames, audio peaks and subtitle timing. Only validated current render can submit/approve. A thumbnail/storyboard never has MP4 ready status.

## Reel iOS

Native navigation: Reel summary/player → Scenes → Scene detail; separately Script, Audio and Subtitles. Preview9:16fits available height, player max300pthigh on390×844; tap full screen enters landscape player with Done. No horizontal multi-track desktop timeline in portrait. Scene list cards72–96pthigh with thumbnail, ordinal, measured/target duration and ready state; Edit reveals reorder handles, VoiceOver actions Move before/after. Scene detail exposes script, duration, crop/source range if video, AI-concept and regenerated asset version. Crop only of decoded source frames, never fake vector layers. Numeric trims use native fields and optional large scrub strip. Bottom safe-area buttons remain above keyboard; Done flushes buffer or invokes Unsaved decision. The native player uses server rendition; app suspension never owns the render process.

## Shared save/conflict rules

Per-output serialized mutation queue. Idle800msautosave; explicit Save now/Done flushes immediately. Capture base revision and local dirty fields; CAS409 compares base/mine/server. Nonoverlapping changes may be proposed merged but require Confirm merge; same-field conflicts require user choice or manual edit. Save resolved with latest expectedRevision; repeated conflict preserves selections and buffer. Local protected storage isolated by user+workspace+entity, expires after30daysinactivity with warning after successful reconnect; never store provider secrets. Delete local buffer only after matching server acknowledgment or explicit Discard. Revision changes reset only dependent approval/checklist. Undo/redo are new revisions; no reversal of publication. Browser refresh recovers route and protected buffer; server fetch first, then reconcile. Navigation confirms only unsynchronized work, never ordinary background jobs.
