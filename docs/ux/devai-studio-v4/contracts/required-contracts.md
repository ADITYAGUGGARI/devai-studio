# Required backend contracts — proposed

These endpoints do not exist in the audited repository. Names and payloads are the handoff target. Preserve legacy routes while migrating; do not wire attractive controls to nonexistent endpoints and call them complete. All resources enforce workspace scope server-side. Every mutation accepts Idempotency-Key and revision precondition where indicated; same key+payload returns original result; same key+different payload → 409 IDEMPOTENCY_MISMATCH. Store action keys for 24h, publication authorizations/attempt reservations durably for lifecycle.

## Shared schema and concurrency
Use opaque UUID entity IDs, RFC3339 UTC instants, explicit IANA timezone. Revision is monotonic integer for new outputs; legacy string versions normalize in adapter, never compare lexicographically. `Error {code,message,fieldErrors:[{path,message}],retryable,retryAfterSec,requestId,currentRevision}` is proposed. No raw provider key, source access token or filesystem path in error responses. `Page {items,nextCursor,asOf}` stable by sort + ID; expired cursor → cursor_expired with safe first-page reload. CAS write uses expectedRevision; 409 returns authoritative revision and changed field paths. Mutations on publishing/published snapshots rejected; duplicate creates new draft.

`Output {id,contentId,format,workingRevision,stage,status,caption,claimSnapshotIds,assetIds,approvedRevision?,renderId?,activeJobId?}`. `Asset {id,outputId,revision,kind,sha256,width,height,durationMs?,validation,provenance,state}`. `Approval {id,outputId,revision,contentHash,assetHashes,captionHash,evidenceHashes,actorId,approvedAt}`. `Publication {id,approvalId,accountId,state,authorizationId,scheduledAtUTC?,localDateTime?,timeZone?,offsetChoice?,attemptId?,externalMediaId?}`. `Render` stores timeline and source asset hashes, measured duration, codecs and validation, not simply boolean “video generated.”

## Eligibility matrix
Owner: create/edit/review/configure/manage people/publish/export/delete. Editor: discover/create/edit/export, no approval or publishing by default; optional publish permission still requires reviewer approval. Reviewer: inspect/approve/request changes, no provider secret access. Owner may self-review personal studio. View-only access is reserved for future expansion; no billing/enterprise organization UX asserted. Server checks all actions regardless of client disabled state.

## Publication timing and authorization
Confirm screen shows exact account, format, version, preview and caption. Snapshot stays frozen through future workspace timezone change. Changing any scheduled account/time/media/caption requires updated explicit authorization; media/caption additionally needs new approval. Scheduler checks credential/permission/media availability before executing; missed slot pauses with “Scheduled time passed; choose Publish now or Reschedule,” never catch-up publish silently. Cancellation and scheduler claim use atomic reservation compare-and-swap. Acceptance of final publish makes result potentially irreversible; persist attempt before call. Unknown outcome keeps reservation locked until confirmed external ID or confirmed nonpublication; still unknown is read-only unresolved. Reconnection does not automatically resume blocked schedules.

## Provider/media acceptance
Product target: carousel 6–8 PNGs 1080×1350; immutable JPEG snapshots for existing Meta path. Reel target H.264 MP4 1080×1920, 30–40 sec, 30 fps, AAC 48 kHz/128kbps when audio, <=25Mbps video; server queries active platform capability limits rather than hardcoding obsolete permissions/hashtag limits. Audio absence is explicit supported choice, not silent failure. Scene stills may be part of video, but only assembled decoded and validated MP4 is final. Uploaded music must have recorded rights/license; no generic copyrighted catalog implied. Burned subtitles use 80px left/right, top160, bottom320 safe zone as product default, adjustable preview with current app chrome warning; safe zone is an editorial target, not an Instagram guarantee.
