# Accessibility and responsive handoff

Target WCAG 2.2 AA web; native VoiceOver/Dynamic Type/Switch Control. This is a design requirement and measurable test plan, not a certified running-product claim. Consult W3C WCAG 2.2 https://www.w3.org/TR/WCAG22/ and Apple accessibility/layout/tab-bar guidelines https://developer.apple.com/design/human-interface-guidelines/accessibility and https://developer.apple.com/design/human-interface-guidelines/layout and https://developer.apple.com/design/human-interface-guidelines/tab-bars. Reference links recorded2026-10-08; Apple article requires JavaScript and was not text-verifiable here. Meta-owned Instagram API reference https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api is an implementation reference; Meta content publishing documentation returned429here. Reel encoding values in this package are product targets, not a claim of fully verified current Instagram limits. Confirm live account capability/version constraints during implementation.

Web: semantic headings/landmarks/labels, skip navigation, aria-current routes, native buttons/links, dialogs with title/description and focus trapping/restoration. All interactions keyboard usable; no drag-only reorder, hover-only explanation or color-only status. Visible 2px focus +2px gap; sticky headers/footers never obscure focused field. Targets product minimum 44×44px, exceeds WCAG AA 24px threshold subject to exceptions. Text contrast 4.5:1 ordinary, 3:1 large; meaningful control boundaries 3:1. Pale border only decorative. Reflow at 320px and 400% zoom without two-dimensional scroll except essential timeline; timeline has equivalent numeric list controls. Video/audio have captions and transcript; explain visual-only information in transcript/scene descriptions. No autoplay; playback accessible time slider; screen reader progress stage announcements throttled, no token/percentage spam. Accessible authentication supports password manager/paste/code autofill, no cognitive puzzle.

iOS: use native NavigationStack, tab bar, system sheets/date-time pickers and media controls; respect runtime safeAreaInsets, do not hardcode modern notch constants. Default visual artboard 390pt width; test 375pt compact and 430pt large, plus 320pt responsive web. Body SF 17pt mapped to system text style; all accessibility Dynamic Type sizes, multiline labels and vertical stacking. Buttons min44pt, accessible names/traits/hints, larger target without invisible overlaps. VoiceOver rotor headings, sequential source/claim context, image copy and truthful video metadata. Accessible Move before/after actions replace drag; adjust duration/cues with numeric fields. Keyboard moves primary action above keyboard, field scrolls into safe region, no multi-line caption hidden by toolbar. Native permission prompt requested only after explanatory Enable push action. System browser OAuth maintains cancel and return flow. In app contrast/increase-contrast/reduce-transparency and Reduce Motion honored.

Responsive layout:
- >=1440: expanded232 sidebar; content max1280 centered; editor rail180, canvas flexible, inspector320; timeline full width below player.
- 1200–1439: expanded232 sidebar; gutters24–32; editor rail180, canvas flexible, inspector320; optional supplemental diagnostics drawer.
- 1024–1199: collapsed72 sidebar with persistent labeled tooltips/focus names; inspector300; rail horizontal; no duplicate top navigation.
- 640–1023: labeled navigation drawer button always visible; 16–24 gutters; two-column collections; editor single canvas with inspector sheet; timeline horizontal but scene-list equivalent.
- 320–639 mobile web: top header + bottom Home/Discover/Content/Activity/Settings; Review/Calendar in Content, Analytics Settings/Home shortcut. Lists one column, filters sheet, form one column, no desktop multi-panel timeline. No automatic assumption this is native iOS.

Native portrait: five tabs preserve stacks, modal editor has Done and independent tools. Primary detail action anchored above safe area while content has equivalent bottom padding. At large type toolbar wraps or moves to menu, headings/fields remain readable. Scene timing is focused sheet, not tiny timeline handles. Landscape: video full-screen playback and image inspection use contain-fit, visible Done, safe-area controls; editable forms may remain portrait while media view supports landscape. Other views adapt layout on window resize rather than rely on device names. No device-local long-running video rendering; server job is source of truth.

Keyboard: Cmd/Ctrl+K opens labeled global search overlay (topics/content/jobs) and Escape closes; Cmd/Ctrl+S flushes editor save, prevented browser save only inside editor; Cmd/Ctrl+Z local undo except native text editing retains text undo; Shift+Cmd/Ctrl+Z redo. Arrow keys within slide strip select, not while typing; Space toggles player only when player focused; Escape closes preview/dialog with unsaved guard. Web global search requires TOPIC/CONTENT/JOB search contracts and each result routes to scoped entity. Global controls: bell → NOT-01, avatar → Profile/Security/Sign out menu, sidebar collapse → local preference, wordmark → Home.

Acceptance gates: keyboard-only complete A–O; VoiceOver actual media review on physical supported iPhone/simulator; AX largest sizes; Windows high contrast/increase contrast; 200% text resize and400% zoom; reduced motion; network reconnect; inaccessible account access; no generic aria-label overriding visible action name. Charts expose downloadable table, metric definition and missing-data reasons. No conformance claim before built-client verification.
