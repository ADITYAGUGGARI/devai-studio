# Modal, sheet and confirmation catalog

| ID | Presentation | Trigger | Title | Body | Primary | Dismiss | Behavior |
|---|---|---|---|---|---|---|---|
| D-APPROVE | Modal / native alert | Approve after checklist complete | Approve this {format} version? | You reviewed version {revision}. Changes to its copy, media or caption will require approval again. | Approve version | Cancel | approval snapshot binds actor + timestamp + content/media hashes; no publish |
| D-PUBLISH | Modal / native sheet | Final publish after successful preflight | Publish to {handle}? | Publish this {format}, version {revision}, with the caption shown. This creates one Instagram post. | Publish now | Cancel | explicit authorization persisted; no retry if outcome unknown |
| D-SCHEDULE | Modal / native sheet | Final schedule with resolved local time | Schedule this post? | {format} v{revision} to {handle} on {date} at {time} {IANA zone} ({offset}). Approved snapshot will be used. | Confirm schedule | Cancel | store UTC + IANA + chosen DST occurrence and authorization |
| D-DELETE | Confirmation / native alert | Delete eligible content | Move this content to Trash? | You can restore it for 30 days. This does not delete posts on Instagram. | Move to Trash | Cancel | blocked if generation or active/uncertain publication; retention date shown |
| D-PERMANENT | Confirmation / native sheet | Purge Trash or post-retention delete | Permanently delete {title}? | Assets and edit history will be removed. This cannot be undone. Type DELETE to confirm. | Delete permanently | Cancel | requires typed DELETE and idle reservations |
| D-UNSAVED | Modal / native alert | Leave editor with unacknowledged edits | Keep your changes? | Changes are not yet saved to the server. Keep editing, save first, or discard this device’s unsaved changes. | Save and leave | Keep editing | third explicit Discard local changes; Save failure stays editor; no deletion of saved revision |
| D-CONFLICT | Comparison / large native sheet | 409 revision mismatch | This version changed on another device | Compare your changes with the latest saved version. Nothing has been overwritten. | Save resolved version | Keep editing | per-field Mine/Server/manual merge; recheck revision at commit |
| D-REGENERATE | Modal / native sheet | Authorize paid replacement | Regenerate {asset}? | The current asset stays in history. This may use provider credits and will invalidate this format’s approval. | Generate new version | Cancel | actual estimate else unavailable; AI concept/version recorded; old asset preserved |
| D-RESTORE | Confirmation / native alert | Restore history snapshot | Restore version {revision}? | A new draft revision will be created. Existing history is preserved and approval must be renewed. | Restore as draft | Cancel | copy into new head, no historic mutation |
| D-DISCONNECT | Confirmation / native alert | Disconnect provider/account | Disconnect {connection}? | Future dependent work will be paused. Accepted publishing attempts may still complete. Your content is retained. | Disconnect | Cancel | show impacted jobs/schedules count; never claim external call recalled |
| D-CANCEL | Confirmation / native alert | Stop eligible generation/research | Stop this job? | Completed assets will be kept. The current external step may finish before the job stops. | Stop job | Keep running | cooperative checkpoint; final publish has no general cancel |
| D-CANCEL-SCHEDULE | Confirmation / native alert | Cancel unclaimed publication | Cancel this scheduled post? | The approved content stays in your library. It will not be sent by this schedule if cancellation succeeds. | Cancel schedule | Keep schedule | compare-and-swap reservation; executing race gives honest cannot-cancel |
| D-ACCOUNT | Large modal / native sheet | Delete account after reauth | Request account deletion? | Export your data first. Deletion is scheduled after 7 days; pending publishing outcomes must be resolved. | Request deletion | Keep account | show exact final date; reauth and owner/remaining workspace policy |
| D-SIGNOUT | Confirmation only if unsynced edits | Explicit sign out | Sign out of this device? | Server jobs and authorized schedules continue. Save or export unsynced changes before signing out. | Sign out | Cancel | clear session; protected local draft prompt; no stopping server worker |
| D-FILTER | Popover / medium-large sheet | Open list filters | Filter {list} | Choose filters. Changes apply only when you select Apply. | Apply filters | Cancel | Clear resets draft values; dismissal discards filter draft |
| D-AUDIO | Picker / native sheet | Music or voice choice | Choose audio | Preview before selecting. Uploaded audio requires rights confirmation. | Use selection | Cancel | no autoplay; selected license stored |
| D-EXPORT | Modal / native sheet | Export assets/metrics | Export {item} | Choose supported format and scope. Missing metrics remain marked unavailable. | Export | Cancel | durable export job; signed link expires; no source secrets |
| D-APPROVAL-EDIT | Inline notice before editing approved output | First material edit | Editing requires a new approval | This format will return to draft when you save these changes. Scheduled versions stay frozen; update the schedule after reapproval. | Continue editing | Cancel | no hidden blanket invalidation of other format |

All dialogs: focus title/least destructive action first; Escape and native close cancel unless mutation already accepted. Backdrop closes only non-destructive pickers. Trap web focus and restore invoker. Native medium/large sheet grows to full height for Dynamic Type or keyboard. Disable duplicate submit during pending request; network failure remains in dialog with input preserved. No dismiss gesture pretends to cancel an accepted durable job.
